Publish to the team automatically

With this on, your plays go to the team site a few seconds after you stop editing, and teammates see them about a minute or two later without reloading.

It needs a GitHub key that can only change this one repo. The key is saved in this browser only, never on the site. Set it up once on each computer or phone you edit on:

  1. Open GitHub's new key page, signed in as the repo owner.
  2. Name it Lions Playbook editor and pick an expiration. A year is fine.
  3. Under Repository access, choose Only select repositories and pick Lions-Basketball-Playbook.
  4. Under Permissions, add Contents and set it to Read and write.
  5. Click Generate token, copy it, and paste it here.

Turning this on publishes the plays in this editor right away, so they become the team's plays.
